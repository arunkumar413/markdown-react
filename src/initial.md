# Markdown-react
A simple markdown editor and previewer based on react and markdown
## Features:
1) Supports headings (h1-h6)
2) Paragraphs
3) Lists
4) [Links](http://google.com)
5) **Bold** text
6) *Italics* text
7) Code blocks using shiki
8) Inline `code` using backticks
## Code block
```js
function Test() {
  console.log("Hello, world");
}
```
